Screenshots for the website and the AppStream metadata go here.

Flathub requires at least one, and the image URLs have to resolve at build
time — which is why they live here, under the published website, rather than
being linked from the repository.

The metainfo references:
  today.png, task.png

Capture them at a sensible window size (around 1200x800) and commit them.

task titles.
