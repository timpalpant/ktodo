KTodo

A native, offline-first Todoist client for KDE Plasma.

Add to your Todoist account Source on GitHub

What it does

  • Works offline Everything is cached locally and edits are queued, so the app is fully usable on a train. Changes replay when you reconnect.
  • Built for Plasma Kirigami and Qt Quick throughout — Breeze styling, KWallet for your token, and native notifications. Not a packaged web page.
  • Projects and sub-tasks Sub-projects, sections and nested sub-tasks, with drag and drop to reorder and move tasks between sections.
  • Team projects Assignees scoped to each project's collaborators, comment threads, and per-role permissions.
  • Dates that behave Due dates, deadlines, priorities and recurring schedules, with natural language parsed exactly as the official clients do.
  • Today, Upcoming, filters Saved filters are evaluated locally, including boolean queries, #project, @label and p1–p4.

Getting started

1. Connect your Todoist account

KTodo reaches Todoist through a registered integration. Install it once, then sign in from the app:

Add KTodo to Todoist

This grants KTodo access to your tasks. You can revoke it whenever you like from Todoist's Settings → Integrations → Connected apps. Your password is never seen by the app — sign-in happens in your browser.

2. Install the app

From Flathub — also how it appears in KDE Discover:

flatpak install flathub io.github.timpalpant.ktodo

On Arch Linux and derivatives:

yay -S ktodo        # or ktodo-git for the development branch

Or build from source:

git clone https://github.com/timpalpant/ktodo.git
cd ktodo
cmake -B build -G Ninja
cmake --build build
./build/ktodo

You will need Qt 6.6+, KDE Frameworks 6 and kirigami-addons. The full dependency list is in the README.
